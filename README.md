# 🚀 Universal Website Scraper (MVP) - Lyftr AI Assignment

A modern, feature-rich web scraper with beautiful UI, supporting both static and JavaScript-rendered websites.

![Scraper Screenshot](https://via.placeholder.com/800x400/2563eb/ffffff?text=Universal+Website+Scraper)

## ✨ Features

- **🌐 Universal Scraping**: Static (HTTPX + BeautifulSoup) & JS-rendered (Playwright) content
- **🎯 Smart Detection**: Automatic JS fallback with heuristic analysis
- **🖱️ Interactive Scraping**: Tabs, load more buttons, infinite scroll, pagination
- **📊 Rich Visualizations**: Charts, statistics, and data insights
- **🎨 Modern UI**: Dark/Light mode, responsive design, smooth animations
- **📥 Multiple Export**: JSON, CSV, Markdown formats
- **🔍 Advanced Filtering**: Noise reduction, section classification
- **📱 Responsive Design**: Works on desktop, tablet, and mobile

## 🛠️ Tech Stack

- **Backend**: FastAPI + Python 3.10+
- **Frontend**: Modern HTML/CSS/JavaScript with Chart.js
- **Scraping**: HTTPX (static), Playwright (JS)
- **Parsing**: BeautifulSoup4, Selectolax
- **UI Framework**: Custom design with Tailwind-inspired CSS
